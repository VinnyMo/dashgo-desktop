Microsoft follow-up — correction and concrete boundary:
The actual bundled licenses/CPython-LICENSE.txt AND the official Python3.14.4
embedding ZIP's LICENSE.txt contain "Additional Conditions for this Windows
binary build". This explicitly addresses onward distribution of Microsoft
Distributable Code, requires protective downstream terms, and says Python
binary redistribution complies subject to listed restrictions (preserve
notices; no misleading Microsoft branding; Microsoft platforms; no malicious,
deceptive or unlawful programs). Thus the earlier blanket statement that the
Python license contained no pass-through wording was incorrect and is corrected.
Python's version-specific documentation expressly supports putting the embedded
distribution in another application's install package:
https://github.com/python/cpython/blob/v3.14.4/Doc/using/windows.rst

Supported conclusion: Python provides a documented redistribution route;
no personal Visual Studio purchase is established as necessary. Retain and
honor its Microsoft-specific terms. The wording initially describes code
embedded by the linker, so do not silently extend it to unrelated Qt runtimes.

For the 8 Qt/Shiboken runtime copies (14.44.35211.0), official wheel metadata
identifies LGPL/GPL alternatives for bindings; its only packaged license file
is LicenseRef-Qt-Commercial.txt and contains no Microsoft downstream grant.
Generic Qt LGPL licensing cannot by itself relicense Microsoft's DLLs.
Qt6.11 deployment guidance both recommends the official redistributable and
warns against fallback developer-machine DLLs, yet elsewhere lists compiler
DLLs inside a deployment archive. Our DLLs match official wheels, not arbitrary
developer-machine files. The guide alone does not resolve permission for those
wheel-supplied files:
https://doc.qt.io/qt-6.11/windows-deployment.html
Microsoft permits app-local redistributable DLL deployment subject to terms:
https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files
The Visual Studio terms permit licensees to authorize downstream distributors:
https://visualstudio.microsoft.com/license-terms/vs2022-ga-community/

of the Microsoft runtime DLLs contained in PySide6/Shiboken6 6.11.0 Windows
wheels, including whether application-local copying is covered and which
protective end-user terms to carry. This can be obtained from Qt or resolved by
